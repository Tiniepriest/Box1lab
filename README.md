# Box1lab

Een openbare, gratis, Nederlandstalige website over het belasting- en toeslagenstelsel: een persoonlijke calculator, een scenariolab en (later) een verkiezingsmodule.

Werktitel; de site draait op GitHub Pages: https://tiniepriest.github.io/Box1lab/

Er is nog geen licentie gekozen. De code is openbaar te bekijken, maar alle rechten zijn voorbehouden. Zie [HANDOFF.md](HANDOFF.md) voor het volledige plan en `prototype/` voor het uitgangspunt.
