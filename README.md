# Box1lab

Een openbare, gratis, Nederlandstalige website over het belasting- en toeslagenstelsel: een persoonlijke calculator, een scenariolab en (later) een verkiezingsmodule.

Werktitel; naam en domein zijn nog niet gekozen. Zie [HANDOFF.md](HANDOFF.md) voor het volledige plan en `prototype/` voor het uitgangspunt.
